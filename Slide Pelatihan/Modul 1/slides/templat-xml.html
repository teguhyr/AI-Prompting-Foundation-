Bab 1.2 · Templat induk

Gabungan 5K + 3P dalam tag XML

<peran> K1 Karakter </peran>
<konteks> K2 Situasi, audiens, tujuan </konteks>
<dokumen> Data atau teks sumber </dokumen>
<instruksi> K3 langkah 1, 2, 3 </instruksi>
<batasan> K5 + alasannya </batasan>
<format_keluaran>
K4 tabel/JSON, batas panjang
</format_keluaran>

Mengapa berhasil

Model tidak lagi mencampur data dengan perintah, dan format hasil terkunci sehingga siap pakai.

Cara memakai

Salin templat, isi tiap tag, hapus tag yang tidak perlu. Untuk dokumen panjang, letakkan dokumen sebelum instruksi.

Penangkal halusinasi

Di tag batasan, tulis: “Jika tidak ada di dokumen, jawab Tidak ditemukan.”
